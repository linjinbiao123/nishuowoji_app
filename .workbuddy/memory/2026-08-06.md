## 修复：Web（Edge/Chrome）编译报错 "File isn't defined"
用户在 Edge(web) 上 `flutter run -d edge` 报错：`lib/pages/home_page.dart:1394:25 Error: The method 'File' isn't defined`，因附件功能最初只按移动/桌面端写，在 UI 直接 import `dart:io` 并用 `File`/`Image.file`，web 平台无 `dart:io` 故编译失败。

### 根因
- `add_record_page.dart` / `history_page.dart` 直接 `import 'dart:io'`。
- `attachment_service.dart` 整个基于 `dart:io`（`Directory`/`File`/`path_provider`）。
- 用户之前在 web 平台运行过，故破坏 web 构建。

### 修复（跨平台条件导入）
- `lib/services/attachment_service.dart` 改为条件导出：`export 'attachment_service_io.dart' if (dart.library.html) 'attachment_service_web.dart';`
  - `attachment_service_io.dart`（新建）：原逻辑，`saveImage(String sourcePath)` 内部 `File(sourcePath).copy(...)`。
  - `attachment_service_web.dart`（新建）：`dirPath()=>''`、`saveImage(p)=>p`（直接存 image_picker 返回的 blob/网络 URL）、`deleteImages` 空操作。
- `lib/widgets/attachment_image.dart`（新建）条件导出 `AttachmentImage`：
  - `attachment_image_io.dart`（新建）：`Image.file(File(path))`。
  - `attachment_image_web.dart`（新建）：`Image.network(path)`（blob: / http(s): 均可用）。
  - 均带 `errorBuilder` 占位，避免坏图崩溃。
- `add_record_page.dart`：删除 `import 'dart:io'`；`saveImage(File(xfile.path))` → `saveImage(xfile.path)`；缩略图改 `AttachmentImage(path: _attachDir.isNotEmpty ? '$_attachDir/$name' : name)`；dispose 仍调 `AttachmentService.deleteImages`（web 实现为空操作）。
- `history_page.dart`：删除 `import 'dart:io'`；列表缩略图与全屏查看器改用 `AttachmentImage`，路径按 `_attachDir` 是否为空决定拼接。
- `home_page.dart`：加 `import '../widgets/attachment_image.dart'`；编辑弹窗附件预览改用 `AttachmentImage(path: attachDir.isNotEmpty ? '$attachDir/$img' : img)`。

## 修复：白底黑字重构后 residual const + getter 编译错误

用户本地 `flutter run -d edge` 报错：多处 `const` 构造函数内部引用 `AppDark` getter，导致"Constant evaluation error" / "The invocation of 'sub/surface' is not allowed in a constant expression"。

### 根因
上一轮全局 `replace_all` 的搜索模式偏窄，遗漏了：
- `const Row(children: [Icon(..., color: AppDark.sub)])`（外层 `Row` 为 const，内部 Icon 用 getter）。
- `const BoxDecoration(color: AppDark.surface)`（`BoxDecoration` 为 const，color 用 getter）。

`AppDark.surface` 固定为深色，但因为它现在是 getter，不能放进任何 `const` 构造函数。

### 修复文件
- `lib/pages/home_page.dart:1453`：`const Row(` → `Row(`（"自定义"分类按钮）。
- `lib/pages/stats_page.dart:366`：`const BoxDecoration(` → `BoxDecoration(`（日历选择器 bottom sheet）。
- `lib/pages/stats_page.dart:537`：`const BoxDecoration(` → `BoxDecoration(`（年份选择器 bottom sheet）。
- `lib/pages/stats_page.dart:923`：`const BoxDecoration(` → `BoxDecoration(`（柱状图点击 day-records bottom sheet）。

## 调整：浅色主题背景漂白为纯白

用户反馈默认浅色主题背景仍是灰蓝色（`0xFF7E8798 / 0xFF5C6471`），不是真·白底。要求改成纯白。

### 改动
- `lib/theme/app_bg.dart`：
  - 默认主题 `简约白` 的 `base` 由灰蓝渐变改为 `[Colors.white, Colors.white]`。
  - `AppBackground` 浅色分支注释更新为"纯白背景"。
  - `GlassCard` 浅色阴影由 `black.withOpacity(0.06)` 略加强到 `0.10`/blur16，避免白卡片在白底上完全糊掉。
- `lib/pages/home_page.dart`、`lib/pages/data_stats_page.dart`：`AnnotatedRegion<SystemUiOverlayStyle>` 由固定 `light` 改为 `AppThemeMode.isLight ? dark : light`，白底配深色状态栏图标。
- SnackBar 背景修复（浅色主题下背景若仍是半透明白会看不见）：
  - `lib/pages/settings_page.dart`
  - `lib/pages/voice_record_dialog.dart`
  - `lib/widgets/vip_widgets.dart`
  - 统一改为 `AppThemeMode.isLight ? const Color(0xFF323232) : theme.base[1].withOpacity(0.96)`，文字改为 `Colors.white`。

### 影响
- 首页、统计、预算、历史等子页面背景均为白色（它们本身是透明 Scaffold，由 `AppBackground` 透出）。
- 记账弹窗、语音弹窗、VIP 弹窗底部 sheet 背景也随 `theme.base` 变白。
- 若用户后续觉得"纯白底 + 白卡片"太单调，可改为微信经典 `#F5F5F5` 浅灰底 + 白卡片。
