## 新增「票据相册」功能

### 起因
用户以为"上传的图片只在当日显示，过了当天就看不到"。

**排查结论：图片并没有丢，是入口太隐蔽。**
- 附件存于 app 私有目录 `attachments/`，`Record.images` 只存文件名。
- 生命周期：只有删除对应记录时才调 `AttachmentService.deleteImages()` 清理，**没有任何按时间过期的逻辑**。
- 原有可见入口只有两处：首页当天列表缩略图、历史账单页逐月翻页缩略图。要找旧票据只能一个月一个月翻。

### ⚠️ Web 端例外（重要，容易误判为 bug）
`attachment_service_web.dart` 的 `saveImage()` 直接把 image_picker 返回的 **blob: URL** 原样存进记录，
不做任何持久化。blob URL 在页面刷新 / 重启后即失效，图片会变成 `broken_image` 占位。
→ 用户若用 `flutter run -d edge` 测试，"图片没了"是**真的**，但这是 web 平台限制，不是相册功能的问题。
→ 真机 (iOS/Android) 上 `attachment_service_io.dart` 走文件复制，图片永久有效。
→ 如果以后要让 web 端也持久化，需改为 IndexedDB 存 base64 / bytes。

### 实现
新文件 **`lib/pages/receipt_gallery_page.dart`**（约 586 行）：
- 数据：`Storage.getAll()` 过滤 `images.isNotEmpty`，按 `time` 倒序。
- 分组：按「年月」聚合，每组显示张数 + 当月支出合计。
- 布局：3 列 `GridView`（`childAspectRatio: 0.74`），格子下方显示分类 + 金额。
- 角标：右上橙色「票」标记 `isInvoice`；右下半透明黑显示多图张数。
- 筛选：`全部 / 仅发票` chip；记录跨多年时额外显示年份 chip 行。
- 交互（用户选定）：点缩略图 → **先弹记录详情**（分类图标/金额/时间/备注/全部附件）→ 再点图进 `ImageViewerDialog` 全屏。
- 空状态分两种文案：完全无图片 vs 筛选无结果。

**`lib/pages/history_page.dart`** 加入口（用户选定位置）：
- 位置：第二行工具栏，`Spacer()` 之后、「日历」按钮之前（放标题行会挤爆宽度）。
- 按钮文案带角标：`票据 12`（`_photoCount` getter 汇总 `images.length`），为 0 时只显示「票据」。
- 新增 `_openReceiptGallery()` + `import 'receipt_gallery_page.dart'`。

### 注意事项（延续昨天的坑）
- `AppDark` 是 getter，新代码全程**未**在含 `AppDark` 的构造上加 `const`。已用扫描脚本确认无新增陷阱。
- 弹窗背景做了主题自适应：`AppThemeMode.isLight ? Colors.white : AppDark.surface`，配合 `AppDark.title/sub` 自动匹配明暗。
  这比项目里其它"固定深色 surface + 白字"的弹窗更正确，后续可参照此写法逐步统一。
- `AttachmentImage` 的 io / web 两个实现签名一致（含 `placeholder` 参数），传自定义 placeholder 是安全的；
  默认 fallback 用 `Colors.white12`，在白底主题下几乎不可见，所以新页面全部显式传了主题适配的 placeholder。

## 🚨 重大发现：`HistoryPage` 是死代码（入口修正）

用户反馈"没看到相册入口"。排查发现**入口装在了一个进不去的页面上**。

### 事实
- `lib/pages/home_page.dart` 的 `IndexedStack` 只有 4 页：
  `_buildAccountPage(记账)` / `StatsPage(统计)` / `BudgetPage(预算)` / `SettingsPage(设置)`。
- 底部导航同样只有这 4 个 tab，**没有「历史账单」**。
- 全项目 grep `HistoryPage` → 只在 `history_page.dart` 自身出现，**从未被任何地方实例化**。
- 即 `lib/pages/history_page.dart`（900+ 行，含完整月历视图、日期筛选、附件缩略图）是**孤儿页面**，
  功能应是早期被 `StatsPage` 取代后忘了删/忘了重新挂载。

### 教训（重要，以后加入口前必查）
**加任何 UI 入口前，先确认宿主页面在导航树中真实可达**：
grep 该页面 class 名，确认在 `IndexedStack` / `Navigator.push` / `routes` 中被引用。
仅凭"文件存在 + 代码看起来是主页面"就下手，会做出用户永远看不到的功能。

### 修正
入口改放 **`lib/pages/stats_page.dart`**（用户最初就建议的"统计"页，且是真实 tab）：
- `_buildHeader()` 内，`Spacer()` 之后、月度/年度 toggle 之前，插入胶囊按钮。
- 样式对齐邻居：`AppDark.cardBg` + `cardBorder` + `BorderRadius.circular(18)`，`photo_library_outlined` 图标。
- 文案：有图显示张数（如 `12`），无图显示「票据」——省宽度，避免头部溢出。
- 新增 `_photoCount` getter（基于已有的 `_records`）、`_openReceiptGallery()`（返回时 `.then((_) => _loadData())` 刷新）。
- 宽度估算：标题 50 + 按钮 ~72 + 间隔 8 + toggle ~126 ≈ 256px，iPhone SE(320-32=288) 下仍不溢出。
- `history_page.dart` 里的入口**保留不动**（无害；若将来重新挂载该页即可直接用）。
