# 2026-08-12

## 新增：账本导入功能
- 目标：支持从其它记账 App 导出的 CSV/Excel(xlsx) 导入到本 App（说记），单机存储零侵入（仅追加写入，不覆盖）。
- 架构：可插拔「导入引擎 + 适配器」模式
  - `lib/services/importer/imported_record.dart`：统一中间模型 `ImportedRecord` + `LedgerAdapter` 抽象接口（canHandle 嗅探 / parse 解析）
  - `csv_adapter.dart`：通用 CSV 适配器（按表头关键词自动识别 金额/日期/类型/分类/备注 列）
  - `xlsx_adapter.dart`：Excel 适配器（zip 魔数嗅探，复用列识别逻辑）
  - `own_format_adapter.dart`：本 App 自有导出格式（表头 时间,类型,分类,金额,备注），优先嗅探、最精准
  - `category_mapper.dart`：分类映射器（同义词别名表 + 关键词包含匹配 + 兜底转自定义分类，绝不丢数据）
  - `parse_utils.dart`：日期/金额/收支方向识别工具
  - `import_engine.dart`：嗅探调度器，新增来源只需追加 Adapter
- `lib/services/storage.dart`：新增 `bulkAdd(List<Record>)` 批量追加落库
- `lib/pages/import_preview_page.dart`：导入预览页（识别汇总 + 未匹配分类校正 + 选目标账本 + 前50条预览），确认后才落库
- `lib/pages/settings_page.dart`：数据管理板块新增「导入账本」入口，用 file_picker 选文件
- 新增依赖：file_picker ^8.0.0、excel ^4.0.6、csv ^5.1.1（已 flutter pub get）

## 修复：导入预览页白屏
- 现象：点击「导入账本」选文件后页面全白。
- 根因：`import_preview_page.dart` 的 `_catRow` 为每个未匹配分类构建 `DropdownButton` 时，若原分类名恰好等于内置分类（如“餐饮”），items 里会出现两个相同 `value`，Flutter 在 build 阶段抛异常，web 上表现为白屏。
- 修复：只在原分类名不在内置分类集合中时才添加“自定义：xxx”选项，并校验当前 value 是否有效。
- 顺手：解析异常时把堆栈也显示出来；错误信息改为可滚动、可复制的 `SelectableText`，方便后续排查。
- `flutter analyze lib/pages/import_preview_page.dart` 无 issue。

## 修复：重复导入导致记录重复
- 现象：同一份 CSV 导入两次后，历史账单里出现完全相同的记录（如两条“报销 出差报销”、两条“红包 朋友结婚”）。
- 根因：`Storage.bulkAdd` 只做简单追加，没有做去重。
- 修复：在 `Storage.bulkAdd` 中按 `ledgerId|isExpense|amount|category|note|time` 组合 key 与已有记录去重；新导入的记录只追加不存在的条目。
- 注意：去重 key 里 amount 用 `toStringAsFixed(2)` 避免浮点误差；time 用 `millisecondsSinceEpoch` 精确到毫秒。
- `flutter analyze lib/services/storage.dart lib/pages/import_preview_page.dart` 无 issue。

## 修复：导入预览页主题未适配
- 现象：截图显示当前浅色主题下，导入预览页仍是深色背景 + 白色文字，和 App 整体风格不一致。
- 根因：`import_preview_page.dart` 把 `Scaffold.backgroundColor` 写死为 `AppDark.cardBg`（深色），大量文字直接使用 `Colors.white`/`Colors.white70`。
- 修复：
  - 在 `initState` 加载 `Storage.getBgIndex()`，build 中取当前 `AppBgTheme`。
  - `Scaffold` 背景使用 `theme.base[0]`，body 用 `AppBackground(theme: theme)` 包装，和其他页面一致。
  - 所有文字颜色改用 `AppDark.title/body/sub/hint`，卡片背景/边框改用 `AppDark.cardBg/cardBorder`，下拉菜单背景改用 `AppDark.cardBg`。
  - 顺手修复 `_buildError` 里 `Expanded` 放在 `mainAxisSize.min` Column 中可能引发的布局异常。
- `flutter analyze lib/pages/import_preview_page.dart` 无 issue。

## 修复：导入预览页返回按钮带“返回”文字
- 现象：截图显示 AppBar 左侧返回按钮旁边（或 tooltip）带有“返回”二字，影响美观。
- 根因：未显式指定 `leading`，默认使用 `BackButton`；在桌面/web 平台 `BackButton` 会渲染文字标签。
- 修复：`import_preview_page.dart` 的 AppBar 显式设置 `leading` 为纯图标 `IconButton(Icons.arrow_back)`，并清空 tooltip。
- `flutter analyze lib/pages/import_preview_page.dart` 无 issue。

## 修复：VIP 激活页复制提示未显示 + 美化
- 现象：点击“复制”设备码后，没有弹出“设备码已复制”的提示；用户希望提示显示得更好看。
- 根因：
  1. `vip_widgets.dart` 中 `_tip` 方法给 `SnackBar.content` 用了 `Center` 包裹，`Center` 在 `SnackBar` 里可能被裁剪。
  2. `SnackBar` 未指定宽度，默认会占满底部，和 BottomSheet 叠加时视觉上不明显。
- 修复：
  - 去掉 `Center`，改用 `Container(alignment: Alignment.center)` + `Row`（对勾图标 + 文字）。
  - 增加 `width: 220` 让提示变成居中胶囊样式。
  - 圆角从 12 改成 24，更像现代 Toast。
  - 文字改成 14 号，并带主题强调色对勾图标。
- `read_lints` 检查 `vip_widgets.dart` 无新增问题。

## 修复：VIP 复制提示显示在错误页面
- 现象：提示 Toast 出现在底部导航后面的设置页，而不是当前激活弹窗内。
- 根因：`ScaffoldMessenger.of(context)` 在 BottomSheet 里拿到的是上层页面 Scaffold，SnackBar 会显示在那个 Scaffold 上。
- 修复：`_tip` 改用 `Overlay.of(context)` 插入 `OverlayEntry`，在页面层级顶部显示一个居中的胶囊 Toast；在 BottomSheet 里定位在底部 110 左右，普通场景定位在底部 60 左右。2 秒后自动移除。
- 顺手保留对勾图标、强调色边框、圆角胶囊样式。
- `read_lints` 检查 `vip_widgets.dart` 无新增问题。
